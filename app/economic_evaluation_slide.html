Metodología de Evaluación Económica

Análisis de Impacto de Modelos de Recomendación

🎯 Enfoque Metodológico: "Test Ácido"

Esta evaluación aplica un enfoque conservador que aísla el impacto directo del modelo de recomendación, midiendo únicamente los casos donde el comportamiento del usuario es directamente atribuible al desempeño del modelo.

✅ True Positive (TP)

Escenario: El modelo recomienda un vino y al usuario le gusta.

Impacto: El usuario tiene mayor probabilidad de quedarse (menor churn), capturando el valor esperado del ticket de recompra.

Causalidad: La satisfacción es directamente atribuible al acierto del modelo.
Fórmula TP
ValorTP = AvgTkt × (1 - Churnlike)
Componentes:
  • AvgTkt: Valor promedio del ticket de compra
  • (1 - Churnlike): Probabilidad de que el usuario se quede tras una experiencia positiva

Interpretación: Valor directo capturado cuando el modelo acierta correctamente.

❌ False Positive (FP)

Escenario: El modelo recomienda un vino que no le gusta al usuario.

Impacto: Aumenta fuertemente la probabilidad de churn, perdiendo el valor del ticket.

Causalidad: La insatisfacción es directamente atribuible al error del modelo.
Fórmula FP
ValorFP = -AvgTkt × Churndislike
Componentes:
  • -AvgTkt: Pérdida del valor del ticket (negativo)
  • Churndislike: Probabilidad de que el usuario se vaya tras una experiencia negativa

Interpretación: Pérdida directa cuando el modelo falla y causa insatisfacción.

✅ True Negative (TN)

Escenario: El modelo correctamente evita recomendar un vino que no le gustaría al usuario.

Impacto: Se calcula el beneficio incremental de hacer una segunda recomendación inteligente vs. perder al usuario.

Causalidad: El beneficio proviene de la capacidad predictiva del modelo.
Fórmula TN
ValorTN = AvgTkt × [((1-Churnlike)×Precision) - (Churndislike×(1-Precision)) - (Churndislike)]
Valor esperado de próxima recomendación:
  • (1-Churnlike)×Precision: Valor si la próxima recomendación es exitosa
  • Churndislike×(1-Precision): Pérdida si la próxima recomendación falla
Valor base actual:
  • (Churndislike): Valor de pérdida posible tras experiencia negativa actual

Interpretación: Beneficio incremental de hacer una segunda recomendación inteligente.

❌ False Negative (FN)

Escenario: El modelo incorrectamente evita recomendar un vino que sí le habría gustado al usuario.

Impacto: Se pierde una oportunidad de generar una experiencia positiva. Se calcula el costo de oportunidad vs. el estado actual (usuario accidentalmente satisfecho).

Causalidad: La pérdida de oportunidad es directamente atribuible al error del modelo.
Fórmula FN
ValorFN = AvgTkt × [((1-Churnlike)×Precision) - (Churndislike×(1-Precision)) - (1-Churnlike)]
Valor esperado de próxima recomendación:
  • (1-Churnlike)×Precision: Valor si la próxima recomendación es exitosa
  • Churndislike×(1-Precision): Pérdida si la próxima recomendación falla
Valor base actual:
  • (1-Churnlike): Probabilidad de retención tras experiencia positiva accidental

Interpretación: Costo de oportunidad por no haber recomendado el vino correcto inicialmente.

Supuestos Metodológicos Clave

  • Relación causal directa: Asumimos que el acierto del modelo → satisfacción → retención, y error → insatisfacción → churn
  • Exclusión de "ruido": No consideramos casos donde el usuario se va pese a buena recomendación (factores externos) o se queda pese a mala recomendación (tolerancia/lealtad independiente)
  • Test conservador: Esta metodología proporciona una medida del "impacto puro" del modelo, sin contaminar con variables externas
  • Enfoque en valor incremental: Para TN y FN, medimos el beneficio adicional vs. el estado base actual del usuario
💡 Nota: Esta metodología de "test ácido" permite una evaluación más rigurosa y defensible del valor real que aporta el modelo de recomendación, aislando su impacto de otros factores del negocio.
