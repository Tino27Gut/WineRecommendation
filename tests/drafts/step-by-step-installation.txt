PASO 1: INSTALAR GOOGLE CHROME EN UBUNTU
wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb

sudo apt update

sudo dpkg -i google-chrome-stable_current_amd64.deb

sudo apt-get install -f


PASO 2: CHEQUEAR VERSIÓN DE GOOGLE CHROME
google-chrome --version

Output >>> Google Chrome 134.0.6998.88


PASO 3: INSTALAR CHROME DRIVER EN UBUNTU
wget https://storage.googleapis.com/chrome-for-testing-public/134.0.6998.88/linux64/chromedriver-linux64.zip

sudo apt install unzip

unzip chromedriver-linux64.zip


PASO 4: MOVER CHROME DRIVER A UNA CARPETA GENERAL DEL SISTEMA Y DAR PERMISOS PARA ACCEDER

sudo mv chromedriver-linux64 /usr/bin/chromedriver

sudo chown root:root /usr/bin/chromedriver

sudo chmod +x /usr/bin/chromedriver

sudo apt install chromium-chromedriver


PASO 5: CREAR VIRTUAL ENVIRONMENT E INSTALAR DEPENDENCIAS

# Crear virtual environment
python3 -m venv .venv

# Activar (Linux/Mac)
source .venv/bin/activate

# Activar (Windows)
.venv\Scripts\activate

PASO 6: INSTALAR PROYECTO Y DEPENDENCIAS NECESARIAS
1. Posicionarse en el directorio raíz del proyecto
2. Ejecutar >>> pip install -e .

¿Qué hace pip install -e .?

1. Instala pandas, numpy, scikit-learn, etc. (definidas en pyproject.toml)
2. Hace tu código importable desde cualquier lugar
3. Modo "editable" - los cambios se reflejan inmediatamente

De esta forma podrás acceder a directorios importandolos directamente

Ejemplo: from src.utils.utils import mi_funcion

SI NECESITAS AGREGAR UNA LIBRERÍA

Agrégala al pyproject.toml en la lista dependencies
Ejecuta pip install -e . otra vez

NOTAS

El archivo .egg-info/ se crea automáticamente (no lo toques)
